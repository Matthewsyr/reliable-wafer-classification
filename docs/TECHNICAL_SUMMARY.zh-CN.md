# 中文技术总结

项目已完成历史实验复核、一次固定范围的几何特征消融、划痕 Precision–Recall 分析和工程整理。结论是：**几何特征值得继续验证，阈值方案不应当作修复；现有证据还不足以声称已经解决最终测试的泛化问题。**

## 先区分两种结果

历史 RF / CNN 的批次验证 Macro-F1 为 85.28% / 84.73%，原始冻结测试降到 44.87% / 45.16%。这些是真实且保留的最终测试结果。测试完成后已经检查过错误样本，后续方向也受到诊断启发，所以不能再将同一测试集描述为“未见独立测试”。本轮没有用它重选或评分新模型。

本轮只使用固定开发集：31,457 张训练、11,307 张调参、11,591 张审计。按“同批次或同图像哈希”的连接组划分，三部分没有批次或完全相同图像跨界。审计集此前也被看过，因此下面都是**探索性开发证据**。三个随机种子仍然只面对同一批 80 张真实划痕，不能把样本数说成 240。

## 几何特征做了什么

原 RF 已有 71 项空间特征，包括方差、协方差。PCA 线性度可以由这些信息计算出来，所以不能把它包装成全新的信息来源。

新增的是一个固定的六项特征块：PCA 线性度，以及窄条带内的失效点占比、相对背景的超额占比、长度跨度、沿线分箱占用率、条带内横向 RMS 宽度。固定扫描方向和宽度；不根据审计结果调整。保持训练行、RF 参数、权重和种子不变，只增加特征，共训练六次 RF。对照 CNN 使用已保存的、训练行完全匹配的三个模型结果。

| 开发审计结果（三种子均值） | 原 RF | RF + 几何 | 匹配 CNN |
|---|---:|---:|---:|
| 九分类 Macro-F1 | 83.88% | 87.22% | 82.39% |
| 真实划痕召回率 | 32.08% | 42.08% | 49.58% |
| 划痕预测精确率 | 50.27% | 90.14% | 20.10% |
| 每千张正常晶圆的总误报 | 12.35 | 7.17 | 33.12 |

RF 三个种子的真实划痕命中数从 25/26/26 增至 31/35/35；正常总误报从 108/90/98 降至 61/55/56。正常→划痕从 9/3/2 降至 1/1/1。审计集旧划痕误报全部改为正常，没有转为其他缺陷；但每个种子都新增了一张正常→划痕，不能宣称所有错误都解决。

三个点估计都改善，比只看平均分更有说服力。按批次/哈希连接组做配对重采样，平均召回增量为 +10 个百分点，描述性 95% 区间约 +0.85～+19.83 个百分点。但该区间不包含之前反复探索所引入的选择影响，也不能替代新数据验证。这个消融只能支持整个特征块，不能断定六项中哪一项贡献最大。

## 为什么 80% Precision 阈值不直接采用

“Precision ≥80%”只是演示性假设，不是工厂确认的成本要求。阈值只在 tune 上选择，所有模型阈值冻结后才进行本轮审计复查。它代表当前样本中的经验精确率，不是置信下界，也不能直接转移到重新训练的模型。

对 RF+几何，固定阈值的审计划痕 Precision 为 83.78%～87.88%，Recall 为 36.25%～38.75%。单看这两项似乎合理，但和它自己的九分类直接取最大分数比较：

| 种子 | 真划痕命中：直接分类→阈值规则 | 正常总误报：直接分类→阈值规则 |
|---|---:|---:|
| 42 | 31→29 | 61→63 |
| 123 | 35→29 | 55→56 |
| 2026 | 35→31 | 56→59 |

既少抓到真划痕，又增加正常总误报，所以拒绝把该阈值规则当作改进。CNN 的阈值规则还有大量“划痕误报转成其他缺陷”的情况，这正是必须一起约束正常总误报的原因。曲线、阈值表、九分类混淆矩阵都已保存。

## 工程交付与边界

保留了历史失败实验、运行环境、协议、模型选择记录、完整九分类结果、原始测试冻结时间和数据哈希。可移植代码包括数据检查、特征提取、训练、阈值冻结和评价；基本测试检查标签、划分、预处理、指标及一次性测试流程。独立复算通过 14,317 项检查，零失败。小规模真实数据运行只验证工程链路，不作为性能证据。

仓库不包含庞大原始数据或模型二进制；提供数据来源、校验值和权重重建/历史输出获取方法。实际训练记录中有两次异常长墙钟时间，可能受系统暂停影响但原因未确认，已保留，未为了好看而重跑。

目前最缺的是未被研究过程看过的新批次数据、可靠工艺/时间信息、专家复核标签和真实漏检/误报成本。不能声称工业可部署。英文报告、错误样本、面试讲解和简历要点都链接在 README 中。
