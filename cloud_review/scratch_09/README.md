# 开发集划痕实验结果

**保留原始 CNN 对照和现有 RF77 复检方案。** B、C 都未达到更换训练方法的预设条件。

A 使用原始训练分布。B 和 C 每轮都替换相同的 80 个正常样本位置，训练步数一致。B 放入真实划痕的重复抽样，C 把训练划痕的失效 die 轨迹移植到训练正常片上。所有评估都使用真实标签。

## 开发选择

同一组 5,670 张有标签晶圆中有 60 张真实划痕、3,999 张正常片。百分比是三次训练的平均值，括号内依次列出种子 42、123、2026 各自的张数。

| 训练方法 | 真实划痕召回（命中张数） | 正常总误报率（误报张数） | 正常→划痕率（误报张数） |
|---|---:|---:|---:|

| B 重复抽取真实划痕 | 41.67%（36、8、31） | 5.22%（134、38、454） | 2.37%（120、4、160） |

## 历史开发审计（探索性复核）

同一组 11,591 张有标签晶圆中有 80 张真实划痕、7,991 张正常片。百分比是三次训练的平均值，括号内依次列出种子 42、123、2026 各自的张数。

| 训练方法 | 真实划痕召回（命中张数） | 正常总误报率（误报张数） | 正常→划痕率（误报张数） |
|---|---:|---:|---:|
| A 原始 CNN | 43.75%（38、22、45） | 3.03%（264、96、366） | 1.90%（205、27、224） |
| B 重复抽取真实划痕 | 44.17%（45、13、48） | 5.56%（292、171、869） | 2.03%（223、4、259） |
| C 合成划痕 | 42.08%（48、25、28） | 3.29%（328、115、345） | 1.15%（232、15、29） |

历史开发审计批次已在此前研究中使用，本轮只用于复核趋势。正式测试集未参与。

### 少报的划痕去了哪里

逐张对齐后，种子 2026 最能说明为什么需要看正常总误报。原始 CNN 把 224 张正常片判成划痕。换成合成训练后，其中 **165 张改判成局部缺陷 Loc，32 张恢复为正常，27 张仍判为划痕**。另有两张原本未判划痕的正常片改判成划痕，因此正常→划痕的总数是 29 张。正常总误报由 366 降至 345，真实划痕却丢掉原先命中的 17 张，没有新找回一张，命中数从 45/80 降至 28/80。这是历史审计中一个种子的具体转移，其他种子的走向可逐项核对。[两分区、三个种子的逐片迁移计数](results/paired_transitions.json)

## 复现和数据质量

- **基线。** 对照上一轮自然分布交叉熵 CNN，两个开发分区、三个种子的九类混淆矩阵有 486/486 个单元格相同。六张混淆矩阵逐格一致。
- **合成。** 三种子七轮共 1,680 个替换位置都与 B 配对。对照有标签开发图，有 1,680 次生成的图不与原图完全相同。供体和底片长宽完全匹配 504 次，轨迹最低保留 90.00%。抽查的 12 组原始像素编辑通过了掩膜与失效 die 检查。
- **对照范围。** C 实际使用的供体和 B 原抽样一致 1,085/1,680 次。C 对 B 衡量同等样本预算下完整合成方案的效果，包含几何筛选与底片选择。
- **伪标签。** 训练正常片中从未见过相同长宽的尺寸层，RF77 票数至少 0.50 且首选划痕时，设计批次命中 7/7，确认分区同一固定阈值命中 10/11。通过预设准入的尺寸层有 0 个，接纳 0 张未标注片。学生 CNN 未训练。 [各尺寸证据与准入条件](RF77.zh-CN.md)

## 下一步

在训练集内按批次留出一折，让模型为未见过的该折晶圆打分，轮换各折。用这些预测找容易被判成 Scratch 或 Loc 的真实正常片，与原始尺寸、失效 die 比例相近的判对样本配对。检查两类误报对训练是否敏感，再决定是否在训练中增加抽取这些正常片的频次。开发选择与审计样本继续留作评价。
若能获得新人工标注，优先在训练正常片未覆盖的尺寸层盲标高分候选，另抽低分对照并保留独立批次，再判断是否启动学生 CNN。
