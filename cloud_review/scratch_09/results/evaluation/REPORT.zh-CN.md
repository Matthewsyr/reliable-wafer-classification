## 配对判断

| 对照 | 开发选择 | 开发审计（探索） |
|---|---|---|
| B 重复真实划痕 对 A 原始 CNN | 至少一种子越界 | 至少一种子越界 |
| C 合成划痕 对 A 原始 CNN | 至少一种子越界 | 至少一种子越界 |
| C 合成划痕 对 B 重复真实划痕 | 至少一种子越界 | 至少一种子越界 |

所有配对按 42、123、2026 三个相同随机种子比较。每个种子均须守住划痕命中、正常总误报和正常→划痕。真实划痕命中或正常总误报至少有一项改善才进入成本复算，仅更改误报类别单列。C 对 B 比较相同替换预算下的整套合成方案。C 的供体还受几何与背景匹配限制，可能与 B 不同。

开发审计批次在历史研究中已使用，只能作为探索性复核。正式测试集未用于本轮实验。
B 和 C 均未达到进入成本模拟所需的改善门槛，本轮保留既有复检方案。
